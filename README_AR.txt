مشروع نقاطي Noqati - نسخة تجريبية

مهم:
- هذا مشروع مصدر وليس APK جاهزاً.
- التطبيق التجريبي يعرض واجهة HTML داخل WebView. التسجيل محلي/تجريبي، ولا توجد حسابات حقيقية أو نقاط قابلة للسحب أو بطاقات Google Play حقيقية أو إعلانات/استطلاعات مدفوعة مدمجة.
- تمت إضافة GitHub Actions لبناء APK تجريبي تلقائياً.

طريقة البناء من الهاتف فقط:
1. فك ضغط NoqatiAndroid_Source.zip.
2. أنشئ مستودعاً جديداً على GitHub من المتصفح.
3. ارفع محتويات مجلد NoqatiAndroid إلى المستودع (تأكد أن مجلد .github موجود؛ قد تحتاج تفعيل عرض الملفات المخفية أو رفعه من واجهة GitHub).
4. افتح تبويب Actions في المستودع وفعّل Actions إذا طُلب ذلك.
5. اختر Build Noqati APK ثم Run workflow، أو ادفع commit إلى main/master.
6. بعد نجاح التشغيل، افتح التشغيل الناجح ثم Artifacts وحمّل Noqati-debug-apk.zip.
7. فك الضغط عن الملف المحمّل لتحصل على app-debug.apk، ثم افتحه للتثبيت إذا سمح الهاتف بذلك.

ملاحظة أمان: لا تضع كلمات المرور أو مفاتيح التوقيع أو بيانات شخصية في المستودع. APK الناتج نسخة debug للاختبار وليس إصداراً جاهزاً للنشر على Google Play.
